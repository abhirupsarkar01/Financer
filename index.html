This is the one to use before switching phones: tap Full backup, then save the file to iCloud Drive (or Files) when your browser prompts you. On the new phone, open Financer, tap Restore backup, and pick that same file from iCloud/Files. On this device only. Everything is saved in this browser's own storage — nothing is sent to any server. That means it won't appear on another phone, iPad, or Mac, and clearing Safari's website data for this page (or switching phones) would erase it. Use Export in Reports occasionally if you want a backup you can keep elsewhere.

This permanently deletes every recurring payment, expense, investment, goal, and incentive stored in this browser for this app, and resets settings back to default. There is no undo — consider using Export year first if you want to keep a copy.
